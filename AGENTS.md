# Agent instructions

## Release notes

Every change to the SDK must add an entry to `playground/misc/misc-3-release-notes.md`, in a `## Next Release` section at the top (create it above the latest version heading if it doesn't exist). Group entries under the same subheadings as the rest of the file: `### 🎁 Features`, `### 🛠️ Improvements` or `### 🐞 Bug fix`.
